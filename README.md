# 데이트 신청 링크 💌

거절 버튼은 도망가고, 수락하면 축하 화면이 열리는 한 페이지짜리 밈 사이트입니다.

## 링크 꾸미기

배포된 주소 뒤에 아래처럼 값을 붙이면 문구가 자동으로 바뀝니다.

```text
https://아이디.github.io/저장소명/?to=상대이름&from=내이름
```

데이트 문구도 바꿀 수 있습니다.

```text
https://아이디.github.io/저장소명/?to=민지&from=철수&plan=이번%20주말에%20영화%20보러%20갈래%3F
```

한글과 띄어쓰기가 포함된 링크는 브라우저가 자동으로 인코딩합니다.

## 공개 주소

```text
https://crazynam.github.io/Test/
```

검색엔진 크롤링은 `robots.txt`와 페이지의 `noindex` 메타 태그로 차단되어 있습니다.
